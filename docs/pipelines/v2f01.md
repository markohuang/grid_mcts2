# Pipeline v2f01 — fixed map 2 reproduction test

**Pipeline id:** `v2f01`
**Bootstrap data:** `/scratch/huang651/grid_mcts2/datasets/wave02f_reverted` (FakeNet, 20k games, fixed map 2, layer_delta reward)

## Hypothesis

H: With the pipeline automation working end-to-end, does a pretrained actor-critic + one cycle of selfplay+train meaningfully improve over the FakeNet baseline on the **fixed map 2** where we have prior benchmarks (Round 04 best = 12)?


## Results (selfplay index comparison)

| | n | avg cost | min | p10 | p50 | p90 | avg game time | policy entropy |
|---|---|---|---|---|---|---|---|---|
| **bootstrap (v2f, FakeNet)** | 20,000 | 23.43 | 13 | 20 | 23 | 27 | 231s | 1.794 |
| **cycle_01 (trained net)** | 20,000 | **17.09** | **10** | 14 | 17 | 21 | 644s | 1.086 |

Headline: avg cost **23.43 → 17.09 = −27% relative**. Min cost **10** (prior Round-04 best on map 2: 12 — pipeline beat it by 2).

Cost distribution collapsed by ~6 points across all quantiles. 3.4% of games reached cost ≤12 (FakeNet: 0%); 8.7% reached ≤13.

## Takeaways

- First end-to-end demo that pipeline training produces meaningfully better selfplay games than a FakeNet baseline.
- **2000 pretrain steps at batch 128 = 256k samples / 480k transitions = 0.53 passes through bootstrap data.** Undertrained relative to the data available, yet still substantial gain — suggests big headroom with more steps.
- MCTS depth went 4.48 → 5.77 with the learned prior (+29%); policy entropy 1.794 → 1.086 (−40%, still healthy).
- Real-net selfplay is 2.79× slower per game than FakeNet (231s → 644s). Expected from NN forward-pass overhead on CPU MCTS.
- Pipeline chain ran clean: pretrain → array → afterok-gated train → pipeline_completed, zero intervention.
